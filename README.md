## 📚 apostilas-fiap

Transformo as aulas da faculdade em apostilas interativas. Cada capítulo explica o porquê, deixa você mexer nos números e termina com perguntas para se testar. São **9 apostilas e 63 capítulos**, em HTML, CSS e JavaScript, com checagem automática antes de cada atualização.

| Apostila | Cap. | O que cobre |
|---|:-:|---|
| 🤖 Machine Learning | 6 | KNN, métricas, validação cruzada, scalers, vazamento de dados e regressão linear, com demos em cima de dados reais |
| 🗄️ Bancos de Dados e SQL | 8 | Modelagem, DDL, DML, agregações, JOINs, views e triggers, com SQL rodando na própria página |
| 🐍 Python e Pensamento Computacional | 9 | Variáveis, decisões, listas, laços, funções, Git e um algoritmo de jogo, com o código rastreado linha a linha |
| 🛡️ Cibersegurança | 6 | Camadas de rede, IP, DNS, catálogo de ataques, criptografia e defesa |
| ☁️ Cloud e AWS | 7 | IAM, EC2, S3, RDS e Lambda, com os custos e os limites que importam |
| 🧠 Redes Neurais e Deep Learning | 8 | Do neurônio ao deep learning, com redes treinando no navegador, e algoritmos genéticos |
| 📊 Estatística com R e Python | 6 | Da pesquisa à correlação, com Python e R lado a lado |
| 🧭 Gestão Ágil e Pitch | 6 | Scrum, user stories, Kanban, limite de WIP, pitch de 5 minutos e UML |
| 🔌 Sistemas Embarcados com ESP32 | 7 | GPIO, LED, Serial, C++ no ESP32, botão e sensor DHT22, com circuitos simulados |

**Como cada capítulo é montado:** abre com a pergunta que sobrou do anterior, explica em camadas (intuição, definição, exemplo resolvido, código comentado e o erro comum) e fecha com quiz, flashcards e uma cola para a prova.

**Para abrir no computador:** não precisa instalar nada. Baixe o repositório e abra o `index.html`, ou rode `python scripts/serve.py` e acesse `http://localhost:4323`.
